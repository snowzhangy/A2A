# A2A 0.2.0 Alpha 2

This prerelease preserves complete validated translations in desktop playback and gives
slower cloned voices more time to finish sentence endings. It includes an optimized
macOS app and an experimental Windows 11 x64 desktop bundle from the same source revision.

## Changes

- Desktop playback sends the full validated translation to TTS, with a longer bounded
  voice budget. Whole-phrase buffering remains optional.
- Leading silence no longer consumes the TTS speech budget. Silent early starts retry
  once; cutoffs are reported, and voice pacing learns from shaped speech.
- Healthy translations and speaker labels get time to finish before original-voice
  restoration. Single-speaker sessions retain early translations while the first voice
  is prepared.
- The Mac app offers a one-worker voice mode to reduce memory and a speaker Reset button.
  The experimental three-second picture delay uses shorter source units.
- Windows policy mirrors the changes, including correctly aligned partial original-voice
  restoration. Golden traces and regressions cover both language directions.

## Downloads and setup

- **macOS arm64:** optimized `A2A.app`, installation instructions and source build metadata.
  Requires macOS 26+, the matching checkout and explicit local model setup. The build is
  ad-hoc signed and not notarized.
- **Windows 11 x64:** the portable Python desktop runtime, source, `A2A-Windows.bat` and a
  compiled WASAPI/shared-mixer DLL. Requires Python 3.12/3.13, uv, dependencies and explicit
  model setup. It is a desktop preview rather than a standalone executable installer.
- Each archive has a SHA-256 checksum. No models, recordings, captions, traces, saved
  voices or machine preferences are included.

See the platform installation instructions in the downloads or `docs/releases/`.
The platforms use different model backends; this release does not claim identical
voice quality or translation accuracy. Use voice matching only with consenting speakers.
Source-volume recovery, devices, A/V sync and model identity remain experimental.
Long translations can finish late or cause catch-up skips; generation remains bounded.

## Verification

The macOS deterministic check passed 301 Swift tests and 159 harness tests, plus SDK and
model-manifest gates. Focused portable parity checks on macOS passed 77 tests with one
environment-dependent skip. Native app startup/reset uses synthetic data without capture
or inference. The Windows workflow compiles the native library and runs runtime/harness
checks without downloading models; installed voices and interactive device/model checks
require a provisioned Windows 11 machine.
